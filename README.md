# Stanovi-Osijek-Bot

## Overview

`stanovi-osijek-bot` is a Python‑based Telegram bot that aggregates rental listings for apartments in Osijek from various online sources (Facebook Marketplace, Facebook groups, Index Oglasnik, Njuškalo). The bot stores listings in a SQLite database, provides filtering capabilities, analytics, and notifies users about new listings or price changes.

## Environment Configuration (`.env`)

Create a file named **`.env`** in the project root with the following keys (replace placeholder values with your actual credentials):

```text
# Telegram bot token obtained from @BotFather
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Optional: PostgreSQL/SQLite connection string (default uses SQLite)
# DATABASE_URL=sqlite:///listings.db

# Playwright storage state for authenticated Facebook access (generated by scripts/generate_fb_state.py)
FACEBOOK_STORAGE_STATE=facebook_state.json

# Logging level (e.g., INFO, DEBUG, WARNING)
LOG_LEVEL=INFO
```

## Prerequisites

1. **Python 3.11+** (the project was developed with Python 3.11).
2. **Git** – to clone the repository.
3. **Docker & Docker‑Compose** (optional, for containerised deployment).
4. **Playwright** – for headless browser automation (used by the Facebook scraper).
5. **Telegram Bot Token** – acquire from the Telegram @BotFather.

## Local Setup Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/stanovi-osijek-bot.git
   cd stanovi-osijek-bot
   ```

2. **Create a virtual environment and install dependencies**
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Install Playwright browsers**
   ```bash
   playwright install chromium
   ```

4. **Generate Facebook authenticated storage state (optional but recommended)**
   - Run the helper script to open a visible browser, log in to Facebook, and save the session cookies.
   ```bash
   python scripts/generate_fb_state.py
   ```
   - Press **Enter** in the terminal after successful login. The script creates `facebook_state.json` which is referenced by the `FACEBOOK_STORAGE_STATE` variable in `.env`.

5. **Create the `.env` file** (see the *Environment Configuration* section above).

6. **Initialise the SQLite database**
   ```bash
   python -c "from database.database import initialise_db; initialise_db()"
   ```
   (Creates required tables if they do not exist.)

7. **Start the Telegram bot**
   ```bash
   python main.py
   ```
   The bot connects to Telegram, fetches listings on schedule, and responds to user commands.

8. **(Optional) Run the debug API**
   ```bash
   python debug_api.py
   ```
   Starts a small Flask server exposing health‑check endpoints.

## Docker Deployment (Optional)

1. Build the Docker image:
   ```bash
   docker build -t stanovi-osijek-bot:latest .
   ```

2. Run with Docker‑Compose (ensure `.env` is present in the project root):
   ```bash
   docker-compose up -d
   ```

The container will start the bot and keep it running in the background.
